# 9. Palindrome Number

- **Platform:** LeetCode
- **Difficulty:** Easy
- **Topic:** Math
- **Problem:** [Palindrome Number](https://leetcode.com/problems/palindrome-number/)

## Approach

Reverse the digits of the integer and compare the reversed value with the original number.

Negative numbers are not palindromes because their minus sign cannot match when read in reverse.

## Complexity

- **Time:** O(d), where d is the number of digits.
- **Auxiliary Space:** O(1).

## Key Insight

The modulo operator (`% 10`) extracts the last digit, while integer division (`/ 10`) removes it.
